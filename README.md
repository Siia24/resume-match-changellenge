# Разбор резюме под вакансию

Мини-прототип к отклику на вакансию [Junior AI Product Manager в Changellenge](https://changellenge.com/vacancy/junior-ai-product-manager/).

## Задача

Студент находит вакансию, отправляет резюме и не понимает, почему не зовут. Прототип берёт текст резюме (вставленный или из файла PDF, DOCX, TXT) и текст вакансии и показывает:

- процент совпадения резюме с требованиями;
- какие требования уже закрыты;
- чего не хватает;
- три правки формулировок, которые можно сразу вставить в резюме.

Это узкий кусок того, что делает [ИИ-Женя](https://changellenge.com/ai-career-assistant/). Логику взяла из своих аудитов карточек в «Находке»: сначала проверка по чек-листу, потом конкретные исправления, без общих советов.

## Инструменты

- Cursor и облачные агенты Cursor: код и правки
- GitHub: репозиторий, ветки, PR
- Vercel: публичная ссылка на MVP
- GigaChat API: сам разбор резюме
- Яндекс Метрика: цели «вставил резюме», «загрузил резюме», «получил разбор», «скопировал правку»

## Как запустить локально

Нужны Node.js 20.9+ и npm. Локально проверялось на Node.js 22.

```bash
npm install
cp .env.example .env.local
```

В `.env.local` впишите `GIGACHAT_AUTH_KEY` из кабинета разработчика Сбера (готовый Authorization key, Base64). Затем:

```bash
npm run dev
```

Откройте http://localhost:3000, вставьте текст резюме или загрузите PDF, DOCX или TXT (до 5 МБ), добавьте текст вакансии и нажмите «Разобрать». Текст из файла читается в браузере и попадает в поле — его можно поправить. Скан без текстового слоя не читается. На сервер уходит уже текст, когда человек нажимает «Разобрать».

Проверки:

```bash
npm test
npm run lint
npm run build
```

`npm test` в том числе читает текст из примеров PDF и DOCX в `lib/fixtures`.

Без ключа кнопка не показывает выдуманный разбор: `/api/analyze` отвечает ошибкой по-русски.

## Переменные окружения

| Переменная | Обязательна | Что это |
|---|---|---|
| `GIGACHAT_AUTH_KEY` | да | Authorization key из кабинета GigaChat, строка Base64 |
| `GIGACHAT_SCOPE` | нет | По умолчанию `GIGACHAT_API_PERS` (физлицо, бесплатный тариф) |
| `GIGACHAT_MODEL` | нет | По умолчанию `GigaChat`. Другой id — если кабинет показывает иное имя |
| `NEXT_PUBLIC_YM_ID` | нет | Номер счётчика Яндекс Метрики. Пусто — счётчик не подключается |

Ключ живёт только на сервере. В браузер уходит уже готовый разбор.

Запросы к GigaChat идут из `/api/analyze`. Токен берётся через `POST https://ngw.devices.sberbank.ru:9443/api/v2/oauth` (заголовок `RqUID`) и кэшируется до `expires_at`. Разбор — `POST https://api.giga.chat/v1/chat/completions`. Это актуальный адрес из документации Сбера (с 17 июля 2026); старый хост `gigachat.devices.sberbank.ru` пока жив, но его выводят из работы.

Оба адреса подписаны сертификатом НУЦ Минцифры. В репозитории лежит официальный корневой сертификат `certs/russian_trusted_root_ca.crt` (Russian Trusted Root CA, скачан с `https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt`). Он добавляется только к HTTPS-агенту этих запросов, вместе с обычными корневыми сертификатами Node. Проверка TLS не отключается.

## Цели Метрики

Идентификаторы лежат в `lib/goals.ts`.

| Цель | Когда срабатывает |
|---|---|
| `paste_resume` | Человек вставил, ввёл или загрузил текст резюме. Один раз за сессию |
| `upload_resume` | Из файла получился текст и он попал в поле резюме |
| `get_analysis` | Разбор успешно показан на странице |
| `copy_fix` | Человек нажал «Скопировать» у правки |

Счётчик подключается в layout, только если задан `NEXT_PUBLIC_YM_ID`. Вебвизор не включается: в форме резюме.

## Деплой на Vercel

Hobby, проект Next.js. Команда сборки — `npm run build`, команда запуска — стандартная. Если в настройках спрашивают версию Node.js, выберите 22.x.

В настройках проекта задайте те же переменные, что в `.env.example`. `NEXT_PUBLIC_YM_ID` попадает в клиентский код на сборке, поэтому его нужно выставить до деплоя, а не только в рантайме.

`/api/analyze` работает на Node.js, не на Edge: нужен обычный `https` и сертификат Минцифры. Лимит функции — 120 секунд, на Hobby это внутри допустимых 300. Не задавайте `NODE_TLS_REJECT_UNAUTHORIZED`. Страница публичная: каждый разбор тратит токены личного тарифа GigaChat.

Токен OAuth запрашивается с порта 9443 через `node:https`, не через Fetch API. Если на Vercel этот вызов упадёт с ошибкой соединения, платформа режет исходящий порт: в интерфейсе будет сообщение «Не удалось связаться с GigaChat».
